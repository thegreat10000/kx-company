# KX Location - Site Web

## Languages utilisées

### Frontend (côté client) :

- **React 18 avec TypeScript** - Framework JavaScript moderne pour l'interface utilisateur
- **Vite** - Outil de build ultra-rapide pour le développement
- **Tailwind CSS** - Framework CSS pour le design
- **shadcn/ui** - Bibliothèque de composants d'interface (boutons, cartes, modals...)
- **Framer Motion** - Animations fluides (comme les transitions sur les cartes)
- **Wouter** - Routage entre les pages (Accueil, Catalogue, Services, etc.)
- **TanStack React Query** - Gestion des données depuis le serveur

### Backend (côté serveur) :

- **Node.js avec Express.js** - Serveur web en JavaScript
- **TypeScript** - Typage pour plus de fiabilité
- **Drizzle ORM** - Connexion à la base de données

### Base de données :

- **PostgreSQL** - Base de données relationnelle pour stocker vos véhicules

### Structure du projet :

- `client/` - Tout le code frontend (pages, composants)
- `server/` - Code backend (API, routes)
- `shared/` - Code partagé (schémas de données)
- `public/images/` - Vos images (logo, voitures, services)
